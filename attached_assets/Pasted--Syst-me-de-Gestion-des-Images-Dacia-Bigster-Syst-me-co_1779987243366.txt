# 📸 Système de Gestion des Images - Dacia Bigster

Système complet pour télécharger, organiser et publier les images Dacia Bigster sur votre site myg-import.com.

## 🎯 Objectif

Importer les images haute résolution (HD) du Dacia Bigster depuis media.dacia.com, les organiser par variante (Journey, Extreme, Expression), générer des versions SD, et créer les fiches produit pour le site web.

- Bibliothèque PIL/Pillow: `pip install Pillow`

## 🐍 Scripts Python Disponibles

### `organiser_images.py`
**Fonction:** Trie automatiquement les images extraites par variante  
**Usage:**
```bash
python3 organiser_images.py [chemin/vers/source]
```
**Résultat:** Images organisées dans structure `Journey/HD`, `Extreme/HD`, `Expression/HD`

### `redimensionner_images.py`
**Fonction:** Convertit images HD en versions SD (1024x768)  
**Usage:**
```bash
python3 redimensionner_images.py
```
**Résultat:** Images SD dans dossiers correspondants `Journey/SD`, etc.

### `verifier_images.py`
**Fonction:** Contrôle qualité, résolutions et formats  
**Usage:**
```bash
python3 verifier_images.py
```
**Résultat:** Rapport `rapport_qualite.json` avec détails

### `generer_fiches_produit.py`
**Fonction:** Crée fiches HTML, JSON et texte pour le site  
**Usage:**
```bash
python3 generer_fiches_produit.py
```
**Résultat:** Fichiers dans dossier `Fiches_Produit/`

## 🔧 Workflow Détaillé

### Étape 1: Télécharger les Images

1. Accédez à: https://media.dacia.com/all-new-bigster-dacia-elevated-essentials/?lang=eng
2. Descendez au bouton "DOWNLOAD ALL ASSETS"
3. Cliquez sur le bouton
4. Une modal apparaît avec les conditions d'utilisation
5. Cochez "I have read and accept the terms of use and download"
6. Cliquez sur "DOWNLOAD HD" (pas "DOWNLOAD LD")
7. Un fichier ZIP télécharge: `Bigster-All-medias-HD.zip` (environ 800 MB)
8. Attendez la fin du téléchargement

### Étape 2: Extraire le ZIP

```bash
# Macintosh/Linux
unzip -d ~/Downloads/bigster_temp ~/Downloads/Bigster-All-medias-HD.zip

# Windows
# Double-cliquez sur le ZIP et extrayez
```

### Étape 3: Organiser par Variante

```bash
python3 organiser_images.py ~/Downloads/bigster_temp
```

Le script va:
- Analyser chaque nom de fichier
- Identifier la variante (JOURNEY, EXTREME, EXPRESSION)
- Copier dans le bon dossier HD

**Résultat attendu:**
```
✅ Journey       45 images
⚠️  Non classées  3 images
📈 Total         48 images
```

### Étape 4: Sélectionner les 8 Meilleures Images par Variante

**Pour chaque variante, sélectionner:**

**Journey (Hybrid 155, Indigo Blue):**
1. Vue de face studio (fond blanc)
2. Profile gauche
3. Profile droit
4. Vue arrière
5. Tableau de bord
6. Sièges intérieurs
7. Photo dynamique sur route
8. Parking/environnement vie quotidienne

**Extreme (TCe 130 4x4, Schiste Grey):**
1. Vue tout-terrain (4x4 action)
2. Franchissement/off-road
3. Profile général
4. Vue arrière
5. Intérieur cuir
6. Finitions premium/jantes
7. Tableau de bord avancé
8. Photo lifestyle haute gamme

**Expression (TCe 100, Entrée de gamme):**
1. Vue frontale design épuré
2. Profile
3. Arrière fonctionnel
4. Intérieur pratique
5. Équipements essentiels
6. Usage quotidien/famille
7. Vue 3/4
8. Détail finition

**⚠️ IMPORTANT:** Supprimer les autres images pour ne garder que 8-10 par variante  
(Cela optimise l'espace disque et facilite la gestion)

### Étape 5: Générer Versions SD

```bash
python3 redimensionner_images.py
```

Convertit automatiquement:
- Dimensions: Les images HD sont redimensionnées en 1024x768
- Format: JPEG, qualité 85%
- Destinat ion: Dossiers `HD/` → `SD/`

**Résultat:**
```
📊 RÉSUMÉ DES OPÉRATIONS
Journey         8 images
Extreme         8 images
Expression      8 images
✓ Redimensionnement complété avec succès!
```

### Étape 6: Vérifier Qualité

```bash
python3 verifier_images.py
```

Vérifie:
- ✅ Résolution HD: min 1920x1440
- ✅ Résolution SD: ~1024x768
- ✅ Format: JPEG uniquement
- ✅ Absence de corruptions

**Rapport généré:** `rapport_qualite.json`

### Étape 7: Générer Fiches Produit

```bash
python3 generer_fiches_produit.py
```

Crée 3 fiches (HTML, JSON, TXT) pour chaque variante:
- Description détaillée
- Spécifications techniques
- Équipements inclus
- Prix avec marge (+1500€)
- Délai de livraison

**Résultats:** Dossier `Fiches_Produit/`

### Étape 8: Publier sur myg-import.com

1. **Connectez-vous** à l'administration du site
2. **Créez 3 listings** (un par variante)
3. **Pour chaque listing:**
   - Titre: Copier depuis `Fiches_Produit/texte_site_*.txt`
   - Description: Copier depuis la fiche HTML/texte
   - Prix: Voir dans `fiche_*.json` (base + 1500€)
   - Images: Uploader les 8 images HD
   - Délai: "4-5 semaines"
   - Stock: "Sur commande"
4. **Publier** les listings

## 🐛 Troubleshooting

### ❓ Images ne téléchargent pas

**Symptôme:** Le ZIP ne télécharge pas après clic sur "DOWNLOAD HD"

**Solutions:**
1. Vérifier la connexion internet (test: ping google.com)
2. Essayer un autre navigateur (Chrome, Firefox)
3. Accepter explicitement les conditions avec la checkbox
4. Essayer depuis un autre appareil si possible
5. Utiliser VPN si problème réseau

### ❓ Les images téléchargées sont en basse résolution

**Symptôme:** Les images sont trop petites (< 1920x1440)

**Solutions:**
1. S'assurer d'avoir cliqué sur "DOWNLOAD HD" (pas "DOWNLOAD LD")
2. Vérifier dans les propriétés du fichier: dimensions réelles
3. Re-télécharger depuis le site

### ❓ Script organiser_images.py ne trouve pas les images

**Symptôme:** "0 images trouvées"

**Solutions:**
```bash
# Vérifier que le dossier source existe
ls -la ~/Downloads/bigster_temp/

# Vérifier la présence de fichiers jpg
find ~/Downloads/bigster_temp/ -name "*.jpg" | wc -l

# Utiliser le chemin absolu complet
python3 organiser_images.py /Users/mathieuguilloux/Downloads/bigster_temp
```

### ❓ Erreur PIL/Pillow lors du redimensionnement

**Symptôme:** "No module named 'PIL'"

**Solutions:**
```bash
# Installer Pillow
pip install Pillow

# Ou spécifier la version Python
python3 -m pip install Pillow

# Vérifier l'installation
python3 -c "from PIL import Image; print('OK')"
```

### ❓ Les images redimensionnées ne font pas 1024x768

**Symptôme:** Rapport qualité montre des dimensions différentes

**Solutions:**
1. Relancer le redimensionnement: certaines images peuvent avoir échoué
2. Vérifier dans `rapport_qualite.json` quelles images posent problème
3. Les images problématiques peuvent être re-traitées manuellement

### ❓ Marge de 1500€ incorrect

**Symptôme:** Prix final ne correspond pas

**Solutions:**
1. Éditer `generer_fiches_produit.py`
2. Modifier la clé `'prix_base'` pour chaque variante
3. Re-exécuter le script

```python
'Journey': {
    'prix_base': 28500,  # ← Modifier ici
    'marge': 1500,
    ...
}
```
